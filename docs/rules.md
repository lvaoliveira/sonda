## common/cognitive-complexity

**Cognitive complexity of functions should not be too high.** Deeply nested and heavily branched functions are hard to understand and change. Cognitive complexity adds 1 per branch, loop, catch or boolean-operator sequence, plus the current nesting depth for nested structures. Threshold: `thresholds.cognitive_complexity`.

## common/function-length

**Functions should not be too long.** Long functions usually do too many things. Threshold: `thresholds.function_lines`.

## common/too-many-parameters

**Functions should not have too many parameters.** Many parameters make calls hard to read; group them into an object. Threshold: `thresholds.parameters`.

## common/todo-comment

**Track TODO and FIXME comments.** TODO, FIXME and XXX comments mark unfinished work that should be tracked.

## js/no-eval

**eval() should not be used.** eval() executes arbitrary strings as code and is a common injection vector.

Noncompliant:

```javascript
eval(userInput);
```

Compliant:

```javascript
JSON.parse(userInput);
```

## js/no-new-function

**The Function constructor should not be used.** new Function(...) compiles strings into code, just like eval().

Noncompliant:

```javascript
const f = new Function('a', 'return a');
```

Compliant:

```javascript
const f = (a) => a;
```

## js/inner-html

**HTML should not be assigned through innerHTML/outerHTML.** Assigning strings to innerHTML or outerHTML can lead to cross-site scripting.

Noncompliant:

```javascript
el.innerHTML = html;
```

Compliant:

```javascript
el.textContent = text;
```

## js/eqeqeq

**Strict equality operators should be used.** `==` and `!=` perform type coercion with surprising results. Comparisons against `null`/`undefined` are allowed.

Noncompliant:

```javascript
if (a == b) { f(); }
```

Compliant:

```javascript
if (a === b) { f(); }
if (x == null) { g(); }
```

## js/assignment-in-condition

**Assignments should not be used as conditions.** `if (x = y)` is almost always a typo for `===`. Wrap in extra parentheses if intended.

Noncompliant:

```javascript
if (x = 5) { f(); }
```

Compliant:

```javascript
if (x === 5) { f(); }
if ((m = re.exec(s))) { g(); }
```

## js/no-debugger

**debugger statements should not be committed.** debugger statements pause execution in any open devtools.

Noncompliant:

```javascript
function f() { debugger; }
```

Compliant:

```javascript
function f() { return 1; }
```

## js/no-var

**let or const should be used instead of var.** var is function-scoped and hoisted, which causes subtle bugs.

Noncompliant:

```javascript
var x = 1;
```

Compliant:

```javascript
let x = 1;
const y = 2;
```

## js/empty-catch

**Exceptions should not be silently swallowed.** An empty catch block hides failures. Handle the error or explain with a comment.

Noncompliant:

```javascript
try { f(); } catch (e) {}
```

Compliant:

```javascript
try { f(); } catch (e) { /* best effort */ }
```

## js/no-console

**console calls should not be left in production code.** Use a proper logger instead of console.* calls.

Noncompliant:

```javascript
console.log('hi');
```

Compliant:

```javascript
logger.info('hi');
```

## ts/no-explicit-any

**The 'any' type should not be used.** `any` disables type checking; prefer `unknown` or a precise type.

Noncompliant:

```typescript
let x: any = 1;
```

Compliant:

```typescript
let x: unknown = 1;
```

## py/no-eval

**eval() and exec() should not be used.** eval()/exec() run arbitrary code and are a common injection vector.

Noncompliant:

```python
eval(user_input)
```

Compliant:

```python
ast.literal_eval(user_input)
```

## py/subprocess-shell

**Commands should not be run through a shell.** shell=True passes the command through /bin/sh, enabling command injection.

Noncompliant:

```python
subprocess.run(cmd, shell=True)
```

Compliant:

```python
subprocess.run(['ls', '-l'])
```

## py/pickle-load

**Untrusted data should not be unpickled.** pickle.load()/loads() can execute arbitrary code embedded in the data.

Noncompliant:

```python
data = pickle.loads(blob)
```

Compliant:

```python
data = json.loads(blob)
```

## py/mutable-default

**Default arguments should not be mutable.** Default values are evaluated once, so a list/dict/set default is shared between calls.

Noncompliant:

```python
def f(items=[]):
    return items
```

Compliant:

```python
def f(items=None):
    return items or []
```

## py/assert-tuple

**assert should not be called on a tuple.** `assert (cond, msg)` asserts a non-empty tuple, which is always true.

Noncompliant:

```python
assert (x > 0, 'x must be positive')
```

Compliant:

```python
assert x > 0, 'x must be positive'
```

## py/bare-except

**Bare except clauses should not be used.** `except:` also catches SystemExit and KeyboardInterrupt. Catch a specific exception.

Noncompliant:

```python
try:
    f()
except:
    pass
```

Compliant:

```python
try:
    f()
except ValueError:
    pass
```

## py/none-comparison

**None should be compared with 'is'.** `== None` can be overridden by __eq__; use `is None` / `is not None`.

Noncompliant:

```python
if x == None:
    pass
```

Compliant:

```python
if x is None:
    pass
```

## java/string-reference-equality

**Strings should be compared with equals().** `==` compares references, not contents, so equal strings may compare unequal.

Noncompliant:

```java
class A { boolean f(String s) { return s == "x"; } }
```

Compliant:

```java
class A { boolean f(String s) { return "x".equals(s); } }
```

## java/weak-hash

**Weak hashing algorithms should not be used.** MD2, MD5 and SHA-1 are broken for security purposes.

Noncompliant:

```java
class A { void f() throws Exception { MessageDigest.getInstance("MD5"); } }
```

Compliant:

```java
class A { void f() throws Exception { MessageDigest.getInstance("SHA-256"); } }
```

## java/empty-catch

**Exceptions should not be silently swallowed.** An empty catch block hides failures. Handle the error or explain with a comment.

Noncompliant:

```java
class A { void f() { try { g(); } catch (Exception e) {} } }
```

Compliant:

```java
class A { void f() { try { g(); } catch (Exception e) { log(e); } } }
```

## java/print-stack-trace

**printStackTrace() should not be used.** Stack traces printed to stderr bypass logging and may leak internals.

Noncompliant:

```java
class A { void f(Exception e) { e.printStackTrace(); } }
```

Compliant:

```java
class A { void f(Exception e) { log.error("failed", e); } }
```

## java/system-exit

**System.exit() should not be called.** System.exit() shuts down the whole JVM, which is rarely what library or server code wants.

Noncompliant:

```java
class A { void f() { System.exit(1); } }
```

Compliant:

```java
class A { void f() { throw new IllegalStateException(); } }
```

## java/system-out

**System.out and System.err should not be used for logging.** Use a logger so output can be filtered, formatted and routed.

Noncompliant:

```java
class A { void f() { System.out.println("x"); } }
```

Compliant:

```java
class A { void f() { log.info("x"); } }
```

## c/no-gets

**gets() should never be used.** gets() cannot limit input size and always allows a buffer overflow.

Noncompliant:

```c
void f(char *b) { gets(b); }
```

Compliant:

```c
void f(char *b, int n) { fgets(b, n, stdin); }
```

## c/unsafe-string-function

**Unbounded string functions should not be used.** strcpy, strcat, sprintf and vsprintf do not check the destination size.

Noncompliant:

```c
void f(char *d, const char *s) { strcpy(d, s); }
```

Compliant:

```c
void f(char *d, const char *s, int n) { snprintf(d, n, "%s", s); }
```

## c/assignment-in-condition

**Assignments should not be used as conditions.** `if (x = y)` is almost always a typo for `==`. Use double parentheses if intended.

Noncompliant:

```c
void f(int x) { if (x = 5) { g(); } }
```

Compliant:

```c
void f(int x) { if (x == 5) { g(); } if ((x = h())) { g(); } }
```

## c/goto

**goto should not be used.** goto makes control flow hard to follow.

Noncompliant:

```c
void f(void) { goto end; end: return; }
```

Compliant:

```c
void f(void) { return; }
```
